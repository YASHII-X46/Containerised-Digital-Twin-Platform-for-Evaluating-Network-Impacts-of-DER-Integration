# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct.

In short: be respectful and constructive, assume good faith, and keep
discussion focused on the engineering. Harassment of any kind is not welcome.

Report unacceptable behaviour to the maintainer through
[GitHub](https://github.com/YASHII-X46), or by opening a private security
advisory if the matter is sensitive. Reports are handled confidentially.
