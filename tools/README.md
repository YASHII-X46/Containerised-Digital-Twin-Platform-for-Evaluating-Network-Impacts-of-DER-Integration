# Offline Tools

This directory contains optional scripts for plots and report artifacts. The
running Docker stack does not depend on these scripts.

## `make_plots.py`

Generates PNG figures from profile and result CSV files.

Expected input directories:

| Path | Contents |
|------|----------|
| `outputs/profiles/` | Scenario profile CSVs |
| `outputs/results/` | Scenario voltage and branch result CSVs |

Output directory:

| Path | Contents |
|------|----------|
| `tools/reports/figures/` | Generated PNG figures |

Run:

```bash
pip install matplotlib numpy pandas
python tools/make_plots.py
```

## `build_report.js`

Builds a Word report from summary JSON files and generated figures.

Expected inputs:

| Path | Contents |
|------|----------|
| `tools/reports/load_summary.json` | Load Engine scenario summaries |
| `tools/reports/sim_summary.json` | Simulation Engine scenario summaries |
| `tools/reports/figures/` | Figures generated by `make_plots.py` |

Output:

| Path | Contents |
|------|----------|
| `tools/reports/Validation_Report.docx` | Generated Word document |

Run:

```bash
npm install -g docx
NODE_PATH="$(npm root -g)" node tools/build_report.js
```
